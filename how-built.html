How This Was Built

This site was written by a team of AI agents working under an AI coordinator, and checked against a library of documents that a person assembled and verified first. This page shows who did what, in what order, and what each agent was told to do. It is built directly from the project’s build log.

The team

One coordinator planned the work and gave each agent a written brief. Agents never talked to each other: every file passed through the coordinator, who accepted each result or sent it back. Some agents ran more than once: the coordinator resumed them with a follow-up message to fix what the fact-checker found.

How facts were checked

  1. Fact cards. Three reader agents read the source documents and wrote fact cards: one fact, a short exact quotation, and the precise place in the document it came from.
  2. First check. A fact-checking agent compared every card with the document before any writer could use it.
  3. Writing. The writers built the chapters, the Cast, the Timeline and the Glossary only from checked cards, citing the source for each fact.
  4. Second check. The fact-checker read the finished pages against the sources and listed what had to change.
  5. Fixes and re-check. The coordinator sent the writers back to fix each item, and the fact-checker checked the fixes again. Every correction was logged; they are listed below.

What the sources couldn’t tell us

The agents were allowed to use only the library. When they needed a document the library did not have, they did not look for it themselves: they wrote the need down and left the claim out. A separate agent, the Source Scout, then searched official government websites for the most important missing documents.
