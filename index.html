How to read this site

  • Small numbers in the text, like [1], point to the document behind each fact. On a computer the note sits in the margin; on a phone, tap the number.
  • Underlined terms, like this one, open a short definition.
  • The Presentation button makes the text larger for a classroom screen. The Dark/Light button changes the colors.
  • In a chapter, the ← and → keys move to the previous or next chapter.
