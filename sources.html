Sources

Every fact on this site comes from one of the documents below: investigations, court records, company filings, and congressional hearings and reports.

What is a “fingerprint”?

Each document is listed with its SHA-256 fingerprint: a 64-character code calculated from every byte of the file. If even one character of the file changed, the code would come out completely different. Recording the code when a file is downloaded, and checking it again later, proves that the file being read is exactly the file that was downloaded.
